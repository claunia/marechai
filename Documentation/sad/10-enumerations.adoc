= Enumerations

The purpose of this section is to describe the various enumerations that classify the artifacts stored in the database.

== Status type

This enumeration lists the status an owned machine can have.

[cols="^1,3", options="header"]
|===
| Value | Description

| Unknown | The status of the owned machine is unknown.
| TestedGood | The last time the owned machine was tested it was working correctly.
| NotTested | The owned machine has never been tested.
| TestedBad | The last time the owned machine was tested it presented problems.
|===

== Company status

This enumeration lists the status of a company.

[cols="^1,3", options="header"]
|===
| Value | Description

| Unknown | The status of the company is unknown or not set.
| Active | The company exists and is active.
| Sold | The company was sold, totally or partially.
| Merged | The company merged with another to form a third company.
| Bankrupt | The company legally filed for bankruptcy.
| Defunct | The company ceased operations for reasons different from bankruptcy.
| Renamed | The company was renamed, possibly with a change of direction.
|===

[cols="^1,3", options="header"]

== Add-on orphan reason

This enumeration classifies why a DLC/add-on software entry appears on the orphan add-ons administrative page.

[cols="^1,3", options="header"]
|===
| Value | Description

| Linked | The DLC is correctly linked to its base software.
| NoBase | The DLC has no base software set.
| SelfReference | The DLC's base software identifier points to itself.
| DanglingFk | The DLC's base software identifier points to a non-existent record.

| MisclassifiedAsGame | The record is classified as Game but carries a "DLC / add-on" genre.

== Media Enumerations

=== Media type

This enumeration lists the types of media. It is maintained in synchronization with the Aaru media type enumeration. Due to its length (700+ values), the complete listing is maintained in the `Aaru.CommonTypes` shared library. The values cover all known optical disc formats, floppy disc formats (by manufacturer and density), game cartridge and card formats, tape formats, removable drive formats, and memory card formats.

=== Dump status flags

This enumeration lists the dump status flags. Values are bit flags that may be combined.

[cols="^1,3", options="header"]
|===
| Value | Description

| 0x00 | The dump status is unknown.
| 0x01 | The dump has been stripped of copy protection (cracked).
| 0x02 | The dump has been manually fixed.
| 0x04 | The dump has been intentionally modified (hacked).
| 0x08 | The dump has been unintentionally modified.
| 0x10 | The dump is piracy, in a manner not described by other flags.
| 0x20 | The dump has been modified to add a trainer or cheat systems.
| 0x40 | The dump has been unofficially translated to another language.
| 0x80 | The dump contains more data than the media indicates it should.
| 0x100 | The dump contains less data than the media indicates it should.
| 0x200 | The dump contains known malware (infected).
| 0x400 | The media used to create the dump contains read errors.
| 0x800 | Different dumpers have achieved the exact same dump using different media (verified).
| 0x1000 | The dump is missing side data; it is unknown if this data is essential.
| 0x2000 | The dump is missing side data; this data is known to be non-essential.
| 0x4000 | The dump is missing side data; this data is known to be essential.
| 0x8000 | The dump belongs to a Compact Disc with non-intentional subchannel damage.
|===

=== File attributes

This enumeration lists the possible attributes a file can have. It is maintained in synchronization with the Aaru file attributes enumeration. Values are bit flags. The complete listing includes 45+ attributes covering Unix, Windows, macOS, and historical filesystem attribute types.
